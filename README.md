# Product Catalog (HTML + CSS + JS)

## Мета
Створити простий веб-додаток без фреймворків.
Додаток показує каталог товарів, дає шукати, фільтрувати, сортувати, і працювати з кошиком.
Кошик зберігається після перезавантаження сторінки.

## Що ти зробиш
1. Зробиш UI контролів.
2. Виведеш товари з масиву в JS.
3. Додаси пошук по назві.
4. Додаси фільтр категорій кнопками.
5. Додаси сортування по ціні.
6. Реалізуєш кошик з кількістю і сумою.
7. Збережеш кошик у localStorage.

## Структура проєкту
project-folder
- index.html
- style.css
- script.js

## Дані товарів
Товари лежать у масиві `products` у файлі `script.js`.

Кожен товар має поля:
- id, унікальний номер
- title, назва
- category, категорія
- price, ціна

Приклад:
```js
{ id: 1, title: "Wireless Mouse", category: "Electronics", price: 499 }
````

## Стан кошика

Кошик зберігається в об’єкті `cart`.

Формат:

* ключ, це id товару як рядок
* значення, це кількість

Приклад:

```js
cart = { "1": 2, "5": 1 }
```

Це означає:

* товар з id 1 у кількості 2
* товар з id 5 у кількості 1

## Як має працювати додаток

### 1. Відображення каталогу

* Додаток бере масив `products`.
* На основі цього масиву створює картки товарів у блоці каталогу.
* Кожна картка показує назву, категорію, ціну.
* Кожна картка має кнопку "Додати в кошик".

### 2. Пошук по назві

* Є поле пошуку.
* При введенні тексту список товарів оновлюється одразу.
* Пошук працює по частковому співпадінню.
* Пошук не залежить від регістру.

Приклад:

* введи "mouse"
* побачиш "Wireless Mouse"

### 3. Фільтр по категоріях кнопками

* Категорії беруться з товарів автоматично.
* Для кожної категорії створюється кнопка.
* Є кнопка "Усі".
* Клік по кнопці категорії оновлює список товарів.
* Активна категорія підсвічується.

### 4. Сортування по ціні

* Є select з варіантами:

  * без сортування
  * ціна за зростанням
  * ціна за спаданням
* При зміні сортування список товарів оновлюється одразу.

### 5. Додавання в кошик

* Натисни "Додати в кошик" на товарі.
* Якщо товару ще немає в кошику, він додається з кількістю 1.
* Якщо товар уже є, кількість збільшується на 1.
* Кошик одразу перерендерюється.

### 6. Кошик

Кошик показує:

* список товарів у кошику
* ціну одного товару
* кількість
* суму по позиції
* загальну кількість товарів
* загальну суму

У кожного товару в кошику є кнопки:

* плюс, збільшити кількість
* мінус, зменшити кількість
* видалити, прибрати позицію

Правила:

* мінус зменшує кількість
* якщо кількість стала 0, позиція зникає
* видалити прибирає позицію одразу

Є кнопка "Очистити кошик".
Вона прибирає всі товари.

### 7. Бейдж кошика

Біля заголовка "Кошик" є бейдж.
Він показує загальну кількість товарів у кошику.
Це сума всіх quantity.

### 8. localStorage

* Кошик зберігається в localStorage після кожної зміни.
* При відкритті сторінки додаток читає localStorage.
* Якщо там є кошик, він відновлюється.
* Після цього кошик одразу показується на екрані.

## Покрокове завдання

### Крок 1. Підготуй файли

Створи папку проєкту і додай:

* index.html
* style.css
* script.js

Підключи CSS і JS в HTML.

### Крок 2. Створи масив товарів

У `script.js` створи масив `products`.
Додай мінімум 8 товарів, 3-4 категорії.

### Крок 3. Підключи DOM елементи

Знайди елементи через `document.getElementById`:

* поле пошуку
* select сортування
* контейнер кнопок категорій
* контейнер каталогу
* контейнер кошика
* елементи суми і кількості
* кнопку очищення кошика

### Крок 4. Створи категорії кнопками

* Збери унікальні категорії з `products`.
* Згенеруй кнопки.
* Зроби активну категорію.
* При кліку оновлюй список товарів.

### Крок 5. Зроби фільтрацію і сортування

Створи функцію, яка повертає масив товарів для показу:

* врахуй пошук
* врахуй активну категорію
* врахуй сортування

### Крок 6. Зроби рендер каталогу

* Очисть контейнер каталогу.
* Створи картки через `createElement`.
* Додай кнопку "Додати в кошик".
* Запиши id товару в `dataset`.

### Крок 7. Зроби кошик

* Створи `cart` як об’єкт.
* Додай функції:

  * addToCart
  * changeQty
  * removeFromCart
  * clearCart

### Крок 8. Зроби рендер кошика

* Пройди по `Object.keys(cart)`.
* Для кожного id знайди товар у `products`.
* Створи рядок кошика з кнопками плюс, мінус, видалити.
* Порахуй загальну кількість і суму.
* Онови бейдж кошика.

### Крок 9. Додай localStorage

* saveCart записує cart в localStorage
* loadCart читає cart з localStorage
* викликай loadCart при старті
* викликай saveCart після кожної зміни кошика

## Тест чекліст

1. Пошук працює одразу при введенні.
2. Категорії перемикаються кнопками.
3. Активна категорія підсвічується.
4. Сортування змінює порядок товарів.
5. Додати в кошик збільшує кількість.
6. Плюс і мінус працюють.
7. Мінус на 1 прибирає товар з кошика.
8. Видалити прибирає позицію.
9. Очистити прибирає все.
10. Після перезавантаження кошик зберігається.

## Додатково

1. Кнопка "Скинути фільтри", очистити пошук, повернути "Усі", повернути "Без сортування".
2. Бейдж біля заголовка "Товари", показує скільки товарів видно після фільтрів.
3. Фільтр по мін і макс ціні.
4. Знижка 10 відсотків якщо сума більше 1000.
